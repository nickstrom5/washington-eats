# wa-eats

Washington State's version of the restaurant products, built from one pipeline (see `../STATE_EATS_PLAYBOOK.md`):

1. **The web leaderboard** of every restaurant in Washington, a private claude.ai Artifact from `site/index.html`
   (https://claude.ai/artifact/JMTsUDg9u5AbQkc167j61d). Its JSON is git-ignored because it carries Google 2021-derived ratings.
2. **Washington Eats**, a free iPhone and iPad app (App Store name "Washington Eats: Restaurants", subtitle "WA State Teriyaki & Food Guide",
   Home Screen "WA Eats"), with no Google-derived data.
3. **Its website** in `docs/`, generated by `scripts/make-site.py`: landing page, four guides, 16 city pages, the web app at `/explore/`,
   privacy, terms. Planned home https://washington.eatsranked.com/.

Built separately from `chi-eats/` and `wi-eats/`, reusing their structure, rules and much of their code (read-only). Washington adds a
direction-aware street key (Seattle's "4th Ave N" and "4th Ave S" are different streets), King County's official food safety rating, a
"not affiliated" rule in the link checker, and a robots.txt rule for research sources.

## Pipeline (`pipeline/`)

| Step | Reads | Writes |
|---|---|---|
| `fetch_overture.py` | Overture Maps 2026-09-23.1 (places, divisions, water) | `data/wa/overture_wa_*.parquet`, state/county outlines |
| `fetch_extras.py` | Overture addresses, Seattle and King County outlines | `data/wa/addresses_wa.parquet`, `calib_areas.json` |
| `official.py` | King County inspections (r878-4sxa), Seattle licenses (wnbq-64tb), LCB On Premise list | `data/wa/official.pkl` (records placed on address points) |
| `listings.py` | Overture eating/drinking listings, UCSD Google Local 2021 (artifact only) | `data/wa/stage1.pkl` |
| `calibrate.py` | stage 1 + official records | `data/wa/calibration.json`, `coverage_county.json` |
| `washington.py` | all of the above + `data/research/` | `site/*.json` (artifact) or, with `WA_APP=1`, `data/app/places.json` |
| `check_websites.py` | `data/wa/website_candidates.json` | `data/wa/website_check.json` |

Full commands are in `CLAUDE.md`.

## Calibration (King County, 2026-10-05)

Every Overture listing inside King County was checked against businesses King County inspected in the last 18 months (same name nearby,
or the same street address with a distinctive name word). Share that matched:

| Listing | King County | Here |
|---|---|---|
| Meta + open in Google 2021 | 81% | artifact: kept, "two sources" |
| Meta only | 49% | artifact: kept, "listing only" |
| Foursquare / BrightQuery only | 12–16% | dropped |
| Google 2021 says closed | 4% | dropped |
| App: Meta, confidence ≥ 0.95 | 81% | kept, "confirmed listing" |
| App: Meta, 0.90–0.95 | 49% | kept, "listing only" |
| App: chain store feeds | 67% | kept |
| App: lower-confidence Meta / BrightQuery ≥ 0.95 | 23% / 27% | dropped |

Chicago (74%) and Wisconsin (76–81%) measured the same. King County restaurants the map data lacks (about 2,760) are added from the
records. Per county, the kept listings hold 58–76% of each big county's liquor-licensed restaurants and taverns (a lower bound; the LCB list
is used for this check only).
